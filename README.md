# 山药蛋工具箱 - 图片级深度 PDF 去水印去图框

给 CAD 出图的 PDF 图纸去水印、去图框。包含两个工具：

| 目录 | 内容 | 适用场景 |
|---|---|---|
| `web/` | 网页工具，浏览器本地处理，文件不上传 | 日常使用，无需安装 |
| `python/` | Python 批量脚本 | 大文件，或需要保留矢量页 |

## 1. 网页工具

用浏览器直接打开 `web/src.html` 即可使用（需联网加载 pdf.js、pdf-lib、pako）。

用法：拖入 PDF → 填页码范围（如 `5-94`）→ 点“预览”核对 → “批量处理并生成 PDF” → “下载结果 PDF”。

- 文件只在本机浏览器里处理，不上传
- 输出分辨率默认 400 dpi；要接近原图清晰度选 600 dpi（更慢、文件更大）
- 如需生成压缩混淆的单文件发布版，见 [`web/构建说明.md`](web/构建说明.md)

## 2. Python 批量脚本

```
pip install pymupdf opencv-python-headless numpy
python python/pdf_qushuiyin.py 输入.pdf --start 5 [--end 94] [-o 输出.pdf]
```

- `--start` / `--end`：处理的页码范围（从 1 开始计，含两端），默认全部
- `--keep-front`：范围外的页原样保留
- `--no-watermark` / `--no-frame`：只做其中一项
- `--pad`：图框涂白时向内多留的像素（默认 3）
- 栅格页：直接改写原图像（不降分辨率），无彩色的页自动存为灰度，体积约减半
- 矢量页：删除水印文字对象、框外内容涂白，图面保持矢量

## 3. 适用条件与原理

- **水印**：灰色斜排文字，以“正片叠底”叠在白底上（白底处为 RGB 128 灰，线条压在水印上）。
  识别 128 灰的粗笔画（CAD 8 号色等细灰线按线宽排除），再按 `原值 = 现值 × 255/128` 反算还原，压在水印下的线条完整保留。
- **图框**：找贯通全图的最粗长线作为内框，右侧最靠左的一根长竖线作为标题栏边线，框外全部涂白（页面尺寸不变）。
- **不适用**：彩色扫描件（资质证书、营业执照等），请用页码范围排除。

## 4. 已知问题

- 个别孤立的细笔画（约 5 像素宽的短斜线）可能残留，每页几处。

## 使用须知

请只处理你有权处理的图纸。
