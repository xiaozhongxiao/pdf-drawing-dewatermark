# 源码与发布版构建

- `src.html`：可读源码，可直接用浏览器打开使用；改功能就改这个文件
- `build.js`：把 `src.html` 压缩混淆成单文件发布版 `index.html`

构建步骤（在本文件夹里）：

```
npm i javascript-obfuscator@4.1.1 html-minifier-terser@7.2.0
node build.js            # 读取 src.html，生成 index.html
```

混淆方式：

- 计算核心（去水印、图框识别、编码）：变量名打乱 + 压缩；不加密字符串，否则逐像素运算会慢 6 倍以上
- 界面、文案和页面水印：字符串 RC4 加密、控制流打乱、插入干扰代码、自我保护（格式化后无法运行）、反调试（打开开发者工具会卡住）
- 页面水印放在闭合 Shadow DOM 里，被删除、隐藏、样式覆盖会在 1.5 秒内自动恢复

环境变量 `DP=0` 关闭反调试，`SD=0` 关闭自我保护，调试发布版时使用。
